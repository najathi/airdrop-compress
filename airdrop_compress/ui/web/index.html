Activity

Images

HEIC, JPEG, PNG, TIFF, GIF, BMP, WebP and AVIF photos are converted for the web.

Output format

Quality & compression

WebP quality
75–85 looks identical to the original for photos.
AVIF quality
AVIF looks good at lower numbers: 50–65 matches WebP 80.
JPEG quality
80–85 is the usual sweet spot. 90+ keeps full colour detail.
Compression effort
Lossless for PNG graphics
Pixel-perfect WebP for screenshots, logos and text. Photos stay lossy.
Progressive JPEG
Loads as a blurry preview first, then sharpens - Google recommends it.

File size

Target file size
Lowers quality (never below 30), then shrinks the image until it fits. Slower.
KB
Common targets: under 100 KB for thumbnails, 200 KB for blog images, 500 KB for hero images.
Skip if the result is larger
For JPEG/PNG/WebP originals that are already well compressed. HEIC is always converted.

Dimensions

Maximum size
Longest edge. A 48 MP iPhone photo is 8064 px - far more than any screen needs.
Responsive sizes
Also saves smaller copies (e.g. photo-800w.webp) for srcset, so phones download less.

Metadata & colour

Photo details (EXIF)
Date, camera and location. Removing them saves a few KB and protects your privacy.
Colour
iPhones shoot in Display P3. Converting to sRGB gives the same colours on every screen and drops the profile.

SEO & compatibility

SEO-friendly file names
IMG_1286 Beach Day.HEIC → img-1286-beach-day.webp. Rename files to describe the picture for the best results.
Also save a JPEG fallback
For <picture> fallbacks, email, and platforms that don't accept WebP or AVIF.

Compare formats

See how big one of your images would be in each format with these settings. Nothing is saved.

Documents

Documents are converted to Markdown (.md) - clean, searchable plain text that opens anywhere.

Limits

Largest document to convert
Very large PDFs can take minutes. Bigger files are skipped.

Supported files

Office, PDF & web
Older formats (via macOS textutil)
Code, config, contacts & calendars (kept as a code block)

Not supported: Pages, Numbers and Keynote files, videos and audio. Scanned PDFs have no text to extract - an OCR plugin could add that.

General

Folders, background behaviour and housekeeping.

Folders

AirDrop folder
Output folder
A folder name inside the AirDrop folder, or a full path such as ~/Pictures/Web.

Behaviour

Only AirDrop files
Skip files that a browser or app downloaded (Chrome, Safari, Slack…).
Notifications
One notification per batch, e.g. "5 images: 12 MB → 3 MB".
Open at login
Starts quietly in the menu bar when you log in.
Files at the same time
More is faster for big batches, but uses more memory.
Check for updates
Once a day, from GitHub. Nothing else is sent.

Housekeeping

Process files already in the folder
Converts everything that's there now. Files converted before are skipped.
Conversion history
Used to avoid converting the same file twice.
Reset settings
Restore every setting to its default. Plugins stay installed.

Plugins

Add new file types and conversions. Plugins run in a sandbox and only do what you approve.

How plugins are kept safe

  • Every plugin is off until you turn it on and approve what it asks for.
  • It runs in a separate, sandboxed process: it can read only the file it's converting and write only its own results. Your other files, this app's settings and history are off limits.
  • No internet and no other programs unless you approved those permissions.
  • If a plugin's files change after you approved it, it's switched off until you approve it again.
